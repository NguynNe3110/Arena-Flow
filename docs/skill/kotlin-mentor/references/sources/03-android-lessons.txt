Khi nào gọi API?

Có 3 kiểu phổ biến (bài 15 bạn chọn 1 kiểu đơn giản trước):

Kiểu A — “Manual refresh” (dễ nhất, recommended cho bạn)

App mở lên: chỉ observe DB

Người dùng bấm “Tải/Refresh” thì mới gọi API

Kiểu B — “Auto refresh on start”

Mở màn hình: nếu DB trống → gọi API 1 lần

Nếu DB có data → show luôn, rồi có thể refresh ngầm (tuỳ)

Kiểu C — “Stale time / Cache TTL” (xịn hơn)

Lưu lastFetchTime

Nếu quá X phút → gọi API, còn chưa quá thì dùng DB

👉 Bài 15 nên làm Kiểu A, sau đó nâng lên Kiểu B, cuối cùng chốt Kiểu C.
