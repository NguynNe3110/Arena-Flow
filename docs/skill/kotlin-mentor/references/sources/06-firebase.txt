🚩 Bài 5 — Coroutines + Flow (cực quan trọng)

Kotlin Coroutines

👉 Nâng cấp:

❌ Trước (callback):
db.collection("users").get().addOnSuccessListener(...)
✔ Sau:
Convert sang:
suspend
Flow

👉 Ví dụ tư duy:

fun getUsers(): Flow<List<User>>

👉 Lợi ích:

Không callback hell
Dễ kết hợp với ViewModel (StateFlow)
🚩 Bài 6 — UI State (Loading / Success / Error)

👉 Đây là cái người mới hay bỏ qua nhưng cực quan trọng

Bạn tạo:
sealed class UiState<T> {
    object Loading
    data class Success(val data: T)
    data class Error(val message: String)
}

👉 ViewModel trả về:

StateFlow<UiState<List<User>>>

👉 UI sẽ:

Loading → show progress
Success → show data
Error → show message

🚩 Bài 8 — Firebase Security Rules (cực kỳ quan trọng)

Firebase Security Rules

👉 Nếu không học cái này:
❗ App bạn = “database public”

Ví dụ rule:
match /users/{userId} {
  allow read, write: if request.auth.uid == userId;
}

👉 Nghĩa là:

User chỉ đọc/ghi dữ liệu của chính nó
